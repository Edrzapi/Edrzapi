# Hi, I'm Ed

I'm a software consultant and technical learning specialist with 8+ years in software engineering and training. I design and deliver programmes in Python, Java, C, C++, C#, JavaScript (Node/Express) and R, from beginner fundamentals through to enterprise backend APIs, data analytics and machine learning systems, and from C/C++ memory management and sockets through to modern frameworks such as FastAPI, Django, Spring Boot and Express.

I founded **Devfoundry** in December 2023 to deliver software consulting and technical training. Working with QA and PTR, I've delivered hundreds of hours of customised learning paths for finance, public sector and SME clients, with learner satisfaction consistently above 95%.

I've worked with QA since 2018. I started as a QA consultant placed at Siemens, building Mendix solutions with TDD, then moved in-house as a developer building training content, a technical trainer leading course development in mobile development and non-functional and data-driven testing, an SDET SME technical specialist building bespoke courses for high-profile clients, and a Principal Technical Learning Specialist designing bootcamp programmes. Since 2023 I've continued to deliver for QA as a contractor through Devfoundry. I hold a BEng in Aerospace Technology from Coventry University.

My day-to-day work spans:

- **Backend engineering:** FastAPI, Django, Spring Boot, Express.js, .NET
- **Cloud and DevOps:** Azure, Terraform, Azure DevOps, Kubernetes, Docker, Argo CD, GitHub Actions
- **Data engineering:** Azure Data Factory, Databricks, Delta Lake, Power BI, Synapse
- **Data science and ML:** pandas, NumPy, TensorFlow, PyTorch, scikit-learn, R
- **Systems programming:** C, C++, socket programming, memory management
- **Testing and automation:** Selenium, Cypress, pytest, JUnit, NUnit, Cucumber, TDD/BDD
- **Databases:** PostgreSQL, MySQL, SQL Server, MongoDB, SQLAlchemy, Hibernate, Entity Framework
- **Mobile:** Android (Kotlin), iOS (Swift/SwiftUI)

This profile is where I keep my teaching material, reference projects, and applied examples. If you're a training manager, a delegate, or a developer reviewing my work, have a look around.

**Certifications:** Azure Data Engineer Associate · Databricks Data Engineer Associate · Terraform Associate · TAP Accredited Trainer (Advanced)
